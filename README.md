# ROI Figure Studio

一个完全本地运行的医学图像 ROI 对比结果图排版工具。图片不会上传到网络。

## 使用方法

1. 双击 `index.html`，建议使用 Chrome 或 Edge 打开。
2. 设置行数、列数，按“从左到右、从上到下”的顺序批量导入图片。
3. 选择“框选 ROI”，在任一主图上拖拽。ROI 会应用到同一行的全部方法图像。
4. 选择“设置箭头”，在放大框内点击目标位置。
5. 在左右面板调整标题、颜色、字号、间距和导出尺寸。
6. 点击“导出 PNG”生成论文插图。

## 功能

- 1–10 行、1–10 列图片矩阵
- 直接读取标准未压缩多页 TIFF（含 Float32 三维体数据）
- 多个 TIFF 自动映射为不同方法列，并同步相同 Z 层
- 自定义 Z 层列表；每个切片拥有独立灰度显示范围，同一切片的所有方法共用
- 行列标签、论文式 `(a1)` 编号
- ROI 框、自动局部放大、连接线、红色箭头
- ROI 可按行同步、按列同步、全局同步或每格独立
- 画布尺寸、颜色、字号、间距等设置
- 当前图片替换、撤销/重做、预览
- 原始画布分辨率 PNG 导出

## 隐私

工具只使用浏览器的 Canvas 和 FileReader API，所有图像都保留在本机内存中，刷新页面后不会保留患者图像。

## 三维 TIFF 使用方法

1. 点击“三维体数据 → 导入多页 TIFF 体数据”。
2. 一次选择多个体数据，或分多次追加；每个 TIFF 都会成为一个方法列。列表中可调整顺序或删除。
3. 在“Z 轴层号”中输入需要对比的层号，例如 `1, 16, 32`。层号从 1 开始：1 为第一层，32 为第 32 层；0、小数和超过数据深度的层号会被拒绝。
4. 软件会按每个切片自身的 1%–99% 数据范围估计显示下限和上限。点击画布中的切片可切换编辑目标，手动修改只影响当前切片；低于下限显示为黑色，高于上限显示为白色，同一切片在不同方法间共用相同范围。
5. 之后与二维图片模式一样框选 ROI、设置箭头并导出。

如果需要“行=方法、列=切片”，勾选“方法作为行（切片作为列）”，并只开启“同列同步 ROI”。这样同一切片在不同方法之间共享 ROI，而不同切片可以使用不同位置。

结果图中的切片标签不显示原始 Z 层号，而是按选择顺序默认编号为“切片1、切片2、切片3……”；真实 Z 层号只用于后台读取对应数据。

当前内置解析器支持标准 TIFF、单通道灰度、未压缩像素，以及 8/16/32 位整数和 32 位浮点数据；压缩 TIFF、BigTIFF 或 RGB 体数据需要先转换。

## 精确 ROI

选中图片后，右侧显示 ROI 的原图像素尺寸。可拖拽框选，再编辑 X、Y、宽度和高度，点击“应用 ROI 像素尺寸”。X/Y 是从 0 开始的像素坐标；宽高至少为 1 像素，超出图像边界的输入会被拒绝。修改支持撤销/重做，并遵循同行/同列同步设置；不同分辨率图像之间按相对位置和大小同步。

放大框按 ROI 实际像素长宽比显示，不再将长方形区域拉伸成正方形。“放大框比例”控制显示框的最大边尺寸。
